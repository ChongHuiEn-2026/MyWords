# Report workspace

Follow [`docs/REPORT_GUIDE.md`](../docs/REPORT_GUIDE.md).

- `drafts/`: one Markdown file per owner, named `section-<numbers>-<role>.md` (for example `section-2.1-2.4-A.md`). Push by 3 Dec.
- `figures/`: screenshots named `fig-NN-short-name.png` using the fixed numbers in the guide's section 5, plus `uml.png` and its source.

Fictional data only. Never put `config.txt`, API keys or real personal data here.
